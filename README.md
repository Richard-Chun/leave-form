# 柔美飯店 · 假單產生器

依「房務」班表自動帶入員工班別時間，一鍵產生可列印的 A4 假單（請假單／加班單／未刷卡證明單），一張 A4 上下兩聯，列印後給員工簽名。

---

## 功能

- **兩種班表來源**：上傳 `AUTO排班資料匯入.xlsx`，或貼上 Google Sheet 公開連結。
- **自動帶入**：選好員工 + 日期後，系統依班表自動填入當天的上下班時間、姓名、職稱。
- **可手動修改**：自動帶入後，所有欄位都能在表單中調整；產生後也能直接點擊單據上的黃底欄位修改文字。
- **三種假單**：請假單、加班單、未刷卡證明單。
- **A4 兩聯（列印清單）**：每張假單填好後「加入列印清單」，可重複加入不同員工、不同類別（請假／加班／未刷卡）、不同日期的假單。列印時系統自動每 2 張排成一張 A4（上聯一張、下聯一張），超過 2 張自動分頁；清單可調整順序、刪除。列印時操作介面自動隱藏。
- **支援的班別格式**：`08-17`、`09-18`、`1030/1930`（含換行）、`0930-1830`、`19-04`、`13-22` 等；`休／例／國／套／補休／年` 等休假類會自動留白供手填。

目前涵蓋 11 位房務人員：小涵(R20)、淑雲(R25)、婉茹(N7)、玉美(F19)、玉樺(R94)、俊傑(R27)、東志(R59)、敏智(F13)、莉莉(R86)、蔡緯宸(R68)、蔡順正(R71)。（班表上未排班者不會出現在選單）

---

## 使用方式

1. 開啟網頁。
2. **步驟 1**：上傳班表 Excel，或貼上 Google Sheet 連結。
3. **步驟 2**：選擇員工、輸入民國年與月份、選擇日期（可從班表預覽直接點日期）。
4. **步驟 3**：選假單類型，確認自動帶入的內容，按「＋ 加入列印清單」。
5. 重複步驟 2–4，加入其他要印的假單（可換人、換類別）。
6. 確認右側清單後，按「列印 / 存PDF」。系統會每 2 張排成一張 A4 印出。

## 部署到 Vercel

1. 把整個資料夾放進 GitHub repo。
2. 到 [vercel.com](https://vercel.com) → New Project → 匯入該 repo。
3. Framework 選 **Other**，直接 Deploy（純靜態，免設定）。

## 部署到 Render

1. 到 [render.com](https://render.com) → New → **Static Site**。
2. 連結 GitHub repo。
3. Build Command 留空；Publish Directory 填 `.`（根目錄）。
4. Create Static Site。

## 本機直接使用

不部署也行：直接用瀏覽器開 `index.html` 即可（需連網以載入 Excel 解析函式庫）。

---

## Google Sheet 連結設定

要讓工具讀取 Google Sheet，需把試算表設為「知道連結的任何人 → 檢視者」：

1. Google Sheet 右上「共用」。
2. 一般存取權改為「知道連結的任何人」、角色「檢視者」。
3. 複製連結貼進工具即可。工具會自動讀取「房務」分頁的班表貼上區。
